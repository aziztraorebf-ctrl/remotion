## Notes techniques

- **Frame chaining** : extraire derniere frame de chaque clip via ffmpeg (`-sseof -0.1 -frames:v 1`) comme ref image pour le clip suivant
- **Audio** : reutiliser `thiaroye-voixoff-v6.mp3` (110s)
- **Assemblage Remotion** : 7x OffthreadVideo muted + Audio ElevenLabs overlay
- **Anti-texte** : tous les prompts contiennent "No text, no banners, no signs, no writing visible anywhere"
- **Seedance audio** : strip et remplacer par narration ElevenLabs (regle standard)
