# MOTS-ROUGES-VERTS — Table de Scan Pre-Prompt

> **Scan obligatoire AVANT tout prompt Seedance i2v Short paper-craft.**
> 12 mots rouges a bannir + remplacements preferes + cas particuliers.

## TABLE PRINCIPALE — 12 MOTS INTERDITS

| Mot INTERDIT | Pourquoi | Remplacement prefere |
|---|---|---|
| **slowly** | Declenche slow-mo liquide/gelatineux en paper-craft. Verbes paresseux = action qui stagne. | Verbe franc direct : `CROSSES`, `TURNS`, `LEANS`, `SHIFTS`, `SCANS`. Pas d'adverbe. |
| **gently** | Idem : adoucit au point d'annuler l'action. Seedance l'interprete comme "a peine bouger". | Verbe direct + intention : `SHIFTS weight`, `ADJUSTS posture`, `LEANS into rail`. |
| **subtly** | Contradiction constante avec la regle "mouvement visible". Seedance = "immobile ou presque". EXCEPTION : avec camera (ex: "subtle dolly-in" = delicate mouvement camera). Pas avec les personnages. | Pour persos : supprimer l'adverbe, garder verbe seul. Pour camera : garder "subtle" autorise. |
| **still** | Synonyme reconnu de "frozen". Declenche statique immediatement. | `observational`, `watchful`, `weight on one leg`, `planted`. Le corps reste mais VIT. |
| **gradually** | Seedance compresse en "presque immediat" OU ignore = pas de transition visible. | Decouper en segments timeline : "SECONDS 0 TO 2: X starts / SECONDS 2 TO 4: X fully [state]". |
| **softly** | Identique a "gently". | Action directe sans adverbe. |
| **barely** | Annule l'action ("barely moves" = ne bouge pas). | Dire ce qui bouge vraiment : `SHIFTS fingers`, `TILTS chin 10 degrees`. |
| **almost** | Flou d'intention : "almost raises hand" = Seedance hallucine le geste complet OU le retire totalement. | Decision binaire : soit l'action a lieu ("raises hand halfway, stops"), soit pas du tout. |
| **frozen** | Rule R-VIVANT-PARTOUT violee. Garantit scene statique. | `observational`, `watchful`, `planted`, `grounded`. Vie organique conservee. |
| **motionless** | Identique frozen. | Idem. |
| **dignified** (piege) | Sur-traduit en paper-craft Thiaroye = "raide comme statue". Contextuellement acceptable si combine avec verbes actifs, mais risque eleve. | Preferer `composed`, `steady`, `grounded` + actions concretes (`CLENCHES jaw`, `SQUARES shoulders`). |
| **remains still** | Double signal immobilite. | `remains [engaged/alert/focused]` + micro-action. |

## MOTS ROUGES COMPLEMENTAIRES — PARTICULES FLOTTANTES (R-NO-PARTICLES, 2026-04-25)

> Interdits dans Gemini ET Seedance. Exception : dust cloud en scene d'action principale (explosion, charge).

| Mot INTERDIT | Pourquoi | Remplacement prefere |
|---|---|---|
| **dust motes** | Grains clignotants, artefact vieux film | Supprimer. Atmosphere via eclairage directionnel. |
| **dust particles** | Idem | Supprimer. |
| **gold dust** | Texture parasite sur les objets precieux | `warm golden light catches [object]` |
| **pollen** | Grain flottant non controlable, artefact | Supprimer. Floraison = `petals scatter at base` |
| **sparkles** | Scintillement artefact parasite | `metallic sheen`, `light catches the blade` |
| **floating particles** | Formulation generique = Seedance hallucine confettis/poussiere aleatoires | Supprimer. |
| **mist particles** | Flou non intentionnel, grain | `low mist hugs the ground` (sans "particles") |
| **fog particles** | Idem | `thin fog layer`, `morning haze` |
| **debris floating** | Mouvement aleatoire non controlable | `rubble settles`, `embers rise` (si action) |

## VERBES VERTS — BANQUE D'ACTIONS MACRO (MAJUSCULES)

**Corps entier** : CROSSES arms, FOLDS arms, SQUARES shoulders, LEANS forward, LEANS back, SHIFTS weight, PIVOTS, TURNS, STRAIGHTENS, HARDENS posture, TENSES.

**Tete / cou** : TILTS head, NODS, SCANS, TURNS head, LIFTS chin, LOWERS gaze, FIXES gaze.

**Visage / machoire** (dot-eyes projects : EVITER reactions faciales par les yeux) : CLENCHES jaw, SETS jaw, PURSES lips, TIGHTENS jaw.

> **INTERDIT sur projets dot-eyes** : `eyes WIDE`, `eyes widened`, `eyes wide open`, `wide-eyed`, `eyes dilated` — Seedance agrandit litteralement les yeux et quitte le style dot. Remplacer par verbes corporels : RECOILS, STAGGERS, BRACES, SHOUTS — mouth OPEN, HANDS TO MOUTH, body STIFFENS.

**Mains / bras** : RAISES hand, LOWERS hand, ADJUSTS collar, ADJUSTS strap, GRIPS rail, CLASPS hands, CLENCHES fist, POINTS, GESTURES.

**Jambes / pieds** : STEPS forward, STEPS back, PLANTS feet, SHIFTS stance, PIVOTS.

**Reactions corporelles (substituer aux reactions oculaires sur dot-eyes)** : RECOILS, STEPS BACK, STIFFENS, BRACES, CLUTCHES [object], HANDS TO MOUTH.

**Environnement continu** : water RIPPLES, waves LAP, gulls GLIDE, smoke CURLS, smoke RISES, dust DRIFTS, wind PULLS [at fabric], flags FLUTTER, paper FLUTTERS.

## CAS PARTICULIERS — NUANCES CONTEXTUELLES

| Cas | Formulation INTERDITE | Formulation AUTORISEE |
|---|---|---|
| Camera dolly delicat | `camera dolly-in subtly` | `subtle dolly-in` (OK : adjectif sur camera) |
| Camera movement lent | `camera moves slowly` | `slow dolly-in` (adjectif sur camera, pas adverbe sur verbe) |
| Vie organique | `subtle life` | `organic vitality` / `micro-shifting bodies` |
| Scene contemplative | `characters are still, contemplative` | `characters are observational, weight shifting, gaze scanning` |
| Entree en scene | `figure enters slowly` | `figure CROSSES from [direction]` |
| Tension emotionnelle | `face hardens gradually` | `SEC 0 TO 2: face neutral / SEC 2 TO 4: jaw CLENCHES, shoulders SQUARE` |
| Regard qui suit | `gaze slowly shifts toward ship` | `gaze TRACKS the approaching ship, head TURNS with it` |
| Hesitation | `hand almost raises` | `hand LIFTS halfway then LOWERS` (binaire, concret) |

---

## REGLE D'OR

> **Verbe franc > adverbe. Binaire > flou. Timeline > gradient.**
>
> Seedance n'interprete pas la nuance. Il execute ce qui est concret OU simplifie en "rien du tout". Chaque adverbe est un risque d'annulation de l'action.
