**Constat (2026-08-03, Gazoduc Acte 1)** : un cartouche comparatif "25 Mds$ vs 13 Mds$" (financier,
chiffres verifies dans le script) a ete juge par Aziz pas assez "punchy" et incoherent avec le ton
d'ouverture du script — "imaginez deux immenses tuyaux" est un registre PHYSIQUE/SENSORIEL, pas
financier. Remplace par un cartouche "echelle physique" (distance en km, 6900 km AAGP vs ~4128 km
TSGP, chiffres deja verifies dans la matiere factuelle du projet) — mieux recu.

**La regle** : quand un overlay informatif (cartouche/stat/chiffre) semble factuellement correct
mais "ne clique pas" pour Aziz, verifier s'il est coherent avec le REGISTRE/TON de l'OUVERTURE du
script (le verbe/l'image qui lance la scene), pas seulement avec l'exactitude des donnees. Un
chiffre vrai mais dans le mauvais registre affaiblit quand meme la scene — il rompt le fil sensoriel
etabli par l'ouverture au profit d'un fil different (ici : abstrait/financier) que rien n'annoncait.

**Comment appliquer** : avant de choisir le CONTENU d'un overlay (quel chiffre, quelle donnee
montrer), relire la premiere phrase du beat/acte concerne et se demander si le registre de
l'overlay (financier, physique, humain, temporel...) fait echo a celui de cette premiere phrase.
Si non, chercher un chiffre/fait different, dans le meme registre, meme si le chiffre initial etait
juste.
