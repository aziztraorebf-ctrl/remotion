Quand on compresse un script deja triple fact-checke (ex : mid-form vers Short), verifier
explicitement si la compression a coupe un **contrepoids narratif** deja etabli dans la version
longue — pas seulement des details factuels isoles. Un climax qui semble factuellement correct en
isolation peut devenir trompeur si le contexte qui l'equilibrait a disparu.

**Why** : sur le Short CFA (2026-07-31), le mid-form gere la tension "devaluer aide MAIS devaluer
punit aussi" via 2 ancrages qui encadrent le climax du Beat 5b — le Beat 5a (contexte concret :
un sac de riz importe dont le prix depend du taux de change) et le Beat 6b (une monnaie qui
s'effondre punit les plus pauvres en premier). Cet equilibre avait deja ete valide une fois dans
le mid-form (note datee du 2026-07-25 : "le beat 1 montrait la devaluation comme un desastre
subi, 5b la presentait comme un outil desirable, sans lien entre les deux" — corrige a l'epoque).
La compression du script pour le Short a retire les Beats 5a et 6b **simultanement**, ce qui a
fait reapparaitre exactement le meme probleme deja corrige dans le mid-form, sans qu'aucun fait
individuel du script Short ne soit faux.

**Methode de verification qui a marche** : plutot que de juger a l'oeil si un climax compresse
"tient encore debout", extraire le **transcript reel** du livrable deja publie/promu (via
ElevenLabs Speech-to-Text sur l'audio du fichier `out/PRET-PUBLICATION/*.mp4`) et comparer
explicitement le texte du Short compresse contre ce transcript — pas contre le script source
(qui peut avoir change entre l'ecriture et le rendu final).

**Fix applique** : reintroduire la tension coupee en une clause courte DANS LA MEME PHRASE du
climax ("...une arme a double tranchant : c'est exactement ce qui s'est passe en 1994") plutot
que de reimporter les beats entiers — retablit le contrepoids sans faire exploser la duree du
Short.

**How to apply** : avant de considerer un script compresse "pret", lister explicitement les
tensions/contrepoids/nuances deja actees dans la version source (chercher les notes "corrige
le" / "contradiction" / "assume" dans le STATUS du projet source), et verifier pour chacune si
la compression les a laisses intacts ou coupes.
