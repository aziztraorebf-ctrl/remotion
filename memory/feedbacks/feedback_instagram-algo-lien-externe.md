# Règle : Pas de lien externe dans les CTA Instagram

**Règle :** Ne jamais écrire "Voir la vidéo sur YouTube" ou tout CTA pointant vers un lien externe dans les posts/carousels Instagram.

**Why :** Instagram détecte les posts qui poussent les utilisateurs hors de la plateforme et réduit leur reach algorithmique. Validé par Aziz (2026-05-31).

**How to apply (CTA d'origine, 2026-05-31) :** CTA validée pour la slide 8 de tous les carousels Kora & Cartes :

> "La vidéo complète est sur notre compte."
> "Cherche @koraetcartes"

Ça garde l'utilisateur dans l'écosystème Instagram (cherche le compte = reste sur Instagram) sans pénalité algorithmique. Il trouve la vidéo sur le profil @koraetcartes.

**S'applique à :** tous les carousels Instagram, toutes les captions de posts, tous les formats.
