Sur le projet carrousels Good News (et par extension production carrousel/beat similaire), Aziz autorise Claude à travailler en autonomie une fois la direction validée, et à appliquer les modifications directement sur les fichiers finaux plutôt que de revalider chaque micro-étape.

**Why:** Une fois l'ambiance + le modèle d'une brique validés (ex: charte lumineuse + paire fait/macro Kenya), répéter la validation pour chaque brique suivante crée de la friction inutile. Aziz juge sur le livrable final assemblé.

**How to apply:** Après validation d'un prototype/modèle de référence, produire l'ensemble (toutes les briques + assemblage) en autonomie, puis présenter le livrable complet. Les ajustements se font sur les fichiers finaux. Ne pas re-poser de question tant que la direction reste dans le cadre validé. Re-signaler seulement si un choix sort du cadre (nouvelle décision structurelle, dépense API, ambiguïté narrative). Voir [[STARTER-PROMPT-carrousel-good-news]].
