## LE CONSTAT
Les VÉHICULES (chars/technicals sprites) fonctionnent en format SHORT (9:16, serré, zoomé) :
on voit l'action de près, le véhicule est lisible (cas Soudan validé). En format WAR-MAP LONG
(16:9 dézoomé sur 3 pays), un véhicule de ~50px crée un CONFLIT D'ÉCHELLE STRUCTUREL :
toujours soit trop petit (illisible) soit trop gros (absurde). Le bon réglage n'existe pas —
on a oscillé sans le trouver parce que le problème est structurel, pas un paramètre.

De plus, 1 seul véhicule par faction qui "glisse" = mouvement fantôme. La force des vidéos Sahel
validées venait de véhicules qui suivaient un MOUVEMENT CRÉDIBLE (trajet lisible), pas un glissement.

## LA DÉCISION
Pour le format War-Map LONG 16:9, incarner les groupes armés par des **JETONS-COMBATTANTS** :
- Jeton circulaire parchemin (style des jetons-visage réfugiés Sahel = différentiel maîtrisé).
- Archétype SILHOUETTE de combattant armé (homme, foulard/turban, kalachnikov) dans le jeton.
- Différenciés par couleur de bordure (rouge JNIM #B14B3C / sombre EIGS #3E2A18) + variation.
- **PLUSIEURS (3-5) par faction**, répartis sur la zone contrôlée (remplit l'espace, montre l'emprise).
- Apparition/poussée/pulsation ORGANIQUE (comble le vide ET porte le mouvement).
- Plus GROS, plus organiques que les véhicules (adaptés au dézoom).

## POURQUOI C'EST MIEUX (résout 3 problèmes d'un coup)
1. ÉCHELLE : un jeton circulaire est lisible à toute échelle (vs véhicule qui a une taille "réelle").
2. VIDE : 3-5 jetons par faction remplissent la zone (vs 1 véhicule perdu).
3. MOUVEMENT : pousser/pulser des jetons = organique, pas de "glissement bizarre" d'un sprite.

## RÈGLE GÉNÉRALE (à graver dans WARMAP-PLAYBOOK)
- Format SHORT serré/zoomé → véhicules-sprites OK (action vue de près).
- Format LONG dézoomé → JETONS (incarnation circulaire), PAS de véhicules-sprites isolés.
- L'incarnation par jetons-visage/silhouette est le différentiel transposable aux deux formats.

## ⚠️ CORRECTION (Aziz 2026-06-07) — les jetons PEUVENT et DOIVENT se déplacer
Les modèles ont dit "jamais de translation" = TROP ABSOLU, FAUX dans notre cas. Preuve : nos
jetons-réfugiés (Israël, Sahel) se déplacent le long de corridors et ça MARCHE. Le déplacement de
jetons est un langage cartographique standard (bannières, unités, flux).
Le vrai problème du véhicule n'était PAS le déplacement — c'était le GLISSEMENT SANS SENS (1 sprite
qui dérive vers nulle part). Un jeton qui bouge AVEC INTENTION (fuir vers un camp, avancer vers une
ville, prendre un territoire) = bon. Un sprite qui glisse sans but = mauvais.

RÈGLE CORRIGÉE : les jetons bougent quand ça RACONTE quelque chose. Le mouvement EST le récit.

## MEUBLER EN CONTINU (le vrai défi, Aziz) — éviter de recréer le problème des chars
Si les jetons apparaissent, se placent, puis restent immobiles 15-20s → MÊME problème que les chars
(statique = vide). Solution : le mouvement raconte le propos à CHAQUE instant :
- AVANT ("ce qui existait") : bleu État se fracture + jetons ARRIVENT et se placent (glissent vers
  leurs positions = déjà vivant, AVANT même que la voix les nomme).
- JNIM nommé : jetons JNIM se DÉPLOIENT pour couvrir la zone rurale (prennent le territoire, la tache
  grandit AVEC eux). Mouvement = expansion.
- EIGS nommé : idem à l'est, formation différente (triangle serré).
- "se combattent" : jetons des 2 camps AVANCENT l'un vers l'autre au front, se heurtent, RECULENT.
- "séparément" : se RÉORGANISENT dans leurs zones.
→ Jamais plantés immobiles. Arriver → prendre territoire → s'affronter → se séparer = le récit.
