## INTENTION GLOBALE DE LA SCÈNE (1 verbe)
**TENIR** — poser le paradoxe et le tenir en tension. La scène est un raisonnement en 4 temps :
*écarter* (les 2 récits) → *révéler* (3 gisements, gradation) → *suspendre* (Yakaar, open loop) → *nuancer* (60%).
Densité = le risque n°1. Antidote : 1 monde, gradation maîtrisée, l'abstrait quitte la carte SANS la rompre.

## DÉCOUPAGE BEAT PAR BEAT

### BEAT A — "Les deux récits" (abs 23.5 → 48s) · ABSTRAIT léger SUR carte intacte
- **INTENTION** : *écarter*. Montrer les 2 récits caricaturaux, puis les balayer ("la réalité se joue ailleurs").
- **SPATIAL/ABSTRAIT** : ABSTRAIT, mais traité EN OVERLAY LÉGER sur la carte recomposée (on ne quitte pas le monde).
- ⚠️ **CORRECTION (Aziz) : NE PAS RE-FISSURER.** Le hook FINIT sur la carte RECOMPOSÉE (fissure disparue, "vérité
  plus précise"). On REPART de cette carte INTACTE, nette. Aucune re-fissure (ça défait le hook = interdit).
  "Hérite de la carte du hook" = CONTINUITÉ : même carte Sénégal recomposée à l'écran, on ne la casse jamais.
- **FORME** : la carte recomposée reste. 2 ÉTIQUETTES se posent de part et d'autre (PAR-DESSUS, sans toucher la carte) :
  GAUCHE "LA MALÉDICTION" | DROITE "LE MIRACLE" (2 mots-noyaux, décision Aziz — cohérent avec le hook qui ose les
  mots opposés). Sur "la réalité se joue AILLEURS" (43.3s) → les 2 étiquettes sont BALAYÉES (glissent vers les bords
  et s'effacent — un balayage, PAS une fissure). "teste EN DIRECT" (48s) = la carte seule, nette, prête à plonger.
- **TRANSITION** : entrée = continuité directe du hook (même carte recomposée intacte). Sortie = on plonge vers le large.
- **SFX** : souffle bas léger à l'apparition des 2 étiquettes · **swoosh** (arrow-whoosh) au balayage.

### BEAT B — "Pas un, TROIS" (abs 48 → 55.6s) · SPATIAL (bascule sur carte)
- **INTENTION** : *annoncer* la gradation. Le pivot qui ouvre les 3 gisements.
- **SPATIAL/ABSTRAIT** : **SPATIAL** → carte. On PLONGE du Sénégal vers son large (Atlantique).
- **FORME** : "trouvé TROIS" (53.6s) → 3 halos pré-apparaissent offshore (on SENT les 3 avant de les nommer), la
  caméra commence sa descente vers le 1er. ⛔ ANTI-DOUBLON : PAS de count-up 8M$ (déjà vu au hook).
- **TRANSITION** : fly-in tendu (départ rapide, arrivée lente — courbe agressive, PAS linéaire).
- **SFX** : 3 ticks discrets (un par halo).

### BEAT C — SANGOMAR (abs 55.6 → 68s) · SPATIAL
- **INTENTION** : *révéler* le 1er, le plus concret (pétrole, opérateurs).
- **SPATIAL** → carte serrée sur le point (-17.15, 13.45), au large de Dakar.
- **FORME** : le gisement n'est PAS un simple point (critique Gemini). Dot + halo sous-marin profond (échelle) +
  ResourceTexture pétrole (or sombre) qui irrigue. Cartouche SANGOMAR / PÉTROLE BRUT.
  Woodside (60.5s) → drapeau AU réel + nom. Petrosen 18% (65.6s) → drapeau SN + part.
  ⭐ Plongée caméra avec pitch (relief), pas un zoom plat.
- **TRANSITION** : la caméra arrive en glissé lent (culmine ~54.6s, 1s AVANT "Sangomar").
- **SFX** : boom sourd sub-bass à l'émergence du dot (poids de la ressource).

### BEAT D — GTA (abs 68.7 → 87.4s) · SPATIAL + bascule export
- **INTENTION** : *révéler* le 2e + *élargir* (le Sénégal devient fournisseur mondial).
- **SPATIAL** → carte. Remonte vers GTA (-17.50, 14.80), sur la FRONTIÈRE SN/Mauritanie (la frontière s'illumine
  = ce que seul le spatial montre : un champ à cheval sur 2 pays, en mer).
- **FORME** : dot GTA + ResourceTexture gaz (bleu-gris). Cartouche GTA / GAZ NATUREL. BP (72.9s) → drapeau GB.
  cargaisons Europe/Asie (77s) → **DÉZOOM** pour cadrer Atlantique+Europe (destinations VISIBLES, précision Aziz) →
  arcs export + **ICÔNES MÉTHANIERS qui GLISSENT le long des arcs** (décision Aziz) vers Europe + Asie. Asset navire
  à générer/trouver (silhouette méthanier vue de dessus, sobre, or sur navy). Tag discret "remplacer le gaz russe".
  "devient un FOURNISSEUR" (87.4s) → l'abstrait monte : noyau CANDIDAT→FOURNISSEUR ANCRÉ proprement (pas par-dessus
  illisible comme dans mon 1er essai — un bandeau dédié, carte assombrie 1s).
- **TRANSITION** : fly Sangomar→GTA rapide. Dézoom tenu pour les arcs.
- **SFX** : whoosh sur les arcs · pulse sur "fournisseur".

### BEAT E — YAKAAR (abs 90.3 → 102.1s) · SPATIAL (open loop)
- **INTENTION** : *suspendre*. Planter la graine rappelée scène 5 + scène 7.
- **SPATIAL** → carte, retour sur la côte (-18.0, 14.2).
- **FORME** : dot DIFFÉRENT — bleu FROID, pulse "en attente", PAS d'opérateur (personne ne l'exploite).
  Cartouche YAKAAR-TERANGA / STATUT : NON ATTRIBUÉ. "plusieurs capitales le regardent" (96.8s) → 2-3 lignes
  pointillées entrantes depuis hors-champ qui s'ARRÊTENT avant de toucher (tension suspendue, convoitise).
  "la plus grosse SURPRISE" (102.1s) → le point pulse 1× fort, reste en mémoire (atténué) pendant la sortie.
- **TRANSITION** : fly GTA→Yakaar. Sortie = la carte s'assombrit pour le beat abstrait suivant.
- **SFX** : pulse froid · drone de tension sous les capitales.

### BEAT F — 60% (abs 109.6 → 123s) · ABSTRAIT
- **INTENTION** : *nuancer*. Le chiffre qui paraît rassurant mais ne dit rien.
- **SPATIAL/ABSTRAIT** : **ABSTRAIT** (un %, un partage). → quitte la carte, mais TENU : la carte (Yakaar encore
  visible) s'ASSOMBRIT et l'overlay 60% se pose ANCRÉ dessus (type WarMapDimmedOverlay), PAS un cut vers du kraft.
- **FORME** : count-up → 60%. "moyenne des émergents" (114.4s) → réglette : 60% se pose au milieu d'une échelle
  "ni scandale / ni jackpot" (sobriété FT/Bloomberg, pas de drama). "ne dit rien sur ce qui DÉCIDE" (122.2s) →
  le 60% se DÉSATURE/pâlit, la carte derrière se RÉ-ÉCLAIRE légèrement = open loop vers scène 2 (les règles).
- **TRANSITION** : entrée = assombrissement carte (tenu). Sortie = la carte revient (pont vers "les règles décident").
- **SFX** : cliquetis numériques rapides sur le count-up · ton bas sourd sur la désaturation (le doute).
