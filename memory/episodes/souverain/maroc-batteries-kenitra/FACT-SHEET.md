## ⚠️ Note critique d'ouverture — angle à ajuster

Le pitch initial parlait du triangle **phosphate Maroc → cobalt RDC → assemblage Kénitra → Europe**. Le fact-check Perplexity révèle :

1. **Aucun lien direct RDC→Kénitra n'est documenté publiquement** (plausible via circuits mondiaux Gotion/VW, mais non confirmé)
2. **Gotion High-Tech n'est PAS un projet chinois pur** : Volkswagen détient **40%** de Gotion Power Morocco → l'angle est **sino-allemand**, pas seulement chinois
3. **BMW non confirmé** sur Maroc batteries — annonce non sourcée publiquement à ce stade
4. **Démarrage T2 2026 (juin) selon sources marocaines officielles**, T3 selon Ecomnews — donc "mi-2026" est plus prudent que "Q3 2026"

**Recommandation Claude** : recentrer le triangle sur ce qui est solidement documenté :
**Chine (Gotion) + Allemagne (VW 40%) → Maroc (gigafactory Kénitra + phosphate OCP) → Marché européen via accord pan-euromed**.

Le cobalt RDC peut être mentionné comme **élément du paysage global** (RDC = 70% mondial, Gotion s'approvisionne via circuits chinois), sans affirmer un flux direct Katanga→Kénitra.

- **Piège 1 (mots)** : "exploitation", "pillage", "coup de force", "rebattu les cartes", "souveraineté retrouvée". L'angle Souverain analyste ne moralise pas — la bascule industrielle se décrit, ne se célèbre pas.

## 10. Hook universel — pourquoi Tokyo/Paris/Montréal est concerné

**Levier direct** :
- Voiture électrique 2026-2030 : Renault Mégane E-Tech, Stellantis 500e, future Peugeot 208e, Cupra Born, VW ID.3 — toutes ces voitures peuvent contenir une batterie assemblée à Kénitra

**Levier indirect** :
- Le pari européen "réindustrialisation batteries" (Northvolt en difficulté en 2024-2025) déplace une partie du jeu vers la rive sud de la Méditerranée
- Premier acte d'un mouvement plus large : Égypte, Algérie, Afrique du Sud sur les rangs — donc Kénitra n'est qu'un signal
