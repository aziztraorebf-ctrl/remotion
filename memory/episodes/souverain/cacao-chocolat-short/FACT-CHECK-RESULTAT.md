## CHIFFRES VERROUILLES (corriges) — A UTILISER DANS LE SCRIPT V3
- Afrique de l'Ouest = **~3/4 (75-77%)** de la production mondiale (PAS 2/3). Source : ICCO Global Review 2020/21.
- Cote d'Ivoire + Ghana = **~60% a deux** (CI ~44%, Ghana ~15%). Source ICCO 2019/20.
- Paysan = **6 a 11% du prix final** (FAO ~10-11% moyenne ; 6% borne basse lait). Dire "moins de 10%".
- Ghana = ~15% production / **~1,5% (2 Mds$) de l'industrie ~130 Mds$ — SELON OXFAM** (citer la source).
- Europe = **~60% des feves ECHANGEES** (importations mondiales), pas de la production totale.
- 70% valeur + 90% marges -> marques + distributeurs (FAO/BASIC). ✅ inchange.
