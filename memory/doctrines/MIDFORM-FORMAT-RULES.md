## Pourquoi ces règles existent

Les Shorts Souverain marchent parce que la densité est compressée sur 90s — l'œil accepte la surcharge. Étirer la même grammaire sur 5 min = saturation cognitive garantie. Le Mid-form n'est PAS un Short × 4. C'est un format avec sa propre grammaire.

**Cible de rétention :** 65%+ pour valider le format. <55% = le format ne tient pas, retour aux Shorts.

| Palier | Durée | Mid-rolls | Usage |

| **B — Monétisation** | 8-9 min | Oui (à partir de 8 min strict) | À viser uniquement si Palier A passe >65% rétention |

**On reste au Palier A pour le premier essai.** Pas de tentation de gonfler à 8 min pour AdSense — c'est le piège des "gourous".

## Structure 4 actes (4-5 min)

Inspirée de Polyphonic, Le Monde Explainer, RealLifeLore (formats <7 min). À adapter, pas à copier mécaniquement.

| Acte | Durée | Rôle | Charge cognitive |
|---|---|---|---|
| **1 — Anomalie** | 0:00-0:45 | Hook factuel + question centrale | Haute (hook dense, 1 chiffre choc) |
| **2 — Démonstration** | 0:45-2:30 | Mécanisme principal expliqué (data + carte) | Très haute (cœur info) |
| **3 — Conséquences** | 2:30-4:00 | Qui paie, qui gagne, qui décide | Moyenne (respirations possibles) |
| **4 — Implication globale** | 4:00-4:45 | Pourquoi Paris/Tokyo/Montréal est concerné | Basse (question ouverte, pas conclusion) |

Chaque acte = transition visuelle marquée (changement de fond, plein écran chiffre, slow zoom map). L'œil doit sentir qu'on change de chapitre.

---

## Règle des respirations (NON-NÉGOCIABLE)

**3-4 respirations obligatoires par Mid-form 4-5 min.**

Une respiration = 2-3 secondes où :
- L'audio se tait OU dit une phrase courte non-informative ("Voilà le résultat.")
- Le visuel est statique ou en motion lente continue (Ken Burns subtil, slow zoom map)
- Aucune nouvelle information ne rentre dans le cerveau

**Pourquoi :** sur 5 min de densité Souverain, le cerveau sature autour de 90-120 secondes. Sans respiration, le viewer décroche même si le contenu est bon.

**Placement type :**
- Fin Acte 1 (~0:40) : hold sur chiffre choc + silence 2s
- Milieu Acte 2 (~1:30) : map qui tourne lentement, audio respire
- Transition Acte 2→3 (~2:25) : plein écran texte court, audio se tait
- Avant question finale (~4:30) : retour carte globale, audio en suspens

---

## Ratio data / map / text (indicatif)

Sur 4-5 min :
- **Map dynamique (Mapbox)** : 40-50% du temps
- **Data-viz (graphiques, chiffres, comparaisons)** : 25-30%
- **Plein écran texte/citation** : 5-10%
- **Hybride (map + overlay data)** : 15-20%

**Anti-pattern :** Mapbox 80% du temps = monotonie même si beau. Le cerveau a besoin d'alternance map/data/text pour rester engagé.

## Script — règles spécifiques Mid-form

### Densité de mots
- **140 mots/min max** pour la voix-off (vs 100-120 mots/min pour les Shorts en TTS GéoAfrique)
- 4 min = ~560 mots max ; 5 min = ~700 mots max
- Au-delà → la voix court après les visuels, format Mid-form ne marche plus

### Multi-perspective explicite (Mid-form uniquement)
Contrairement au Short qui peut citer 1 fait et laisser le viewer assembler, le Mid-form **DOIT** citer au moins 2 perspectives factuellement :

- "Le gouvernement X affirme A. Le rapport Y indique B."
- "Pour les multinationales, c'est C. Pour les États producteurs, c'est D."
- "Bloomberg lit l'événement comme E. Jeune Afrique le lit comme F."

Cette règle est **propre au Mid-form**. Sur un Short, elle est impossible (60-90s). Sur 4-5 min, elle devient le bouclier anti-militantisme.

### Test "image dans la tête" — toujours valable
Chaque phrase doit toujours générer une image. Si une phrase demande un schéma pour être comprise → format Long (8 min+), pas Mid-form.

### Chiffres
- Short : 3 max
- Mid-form : 6-8 max (1 toutes les ~40s)
- Au-delà → effet "rapport FMI", perte d'émotion

---

## Visuels — règles spécifiques

### Mapbox
- Pitch entre 0° et 60° (au-delà = vertige sur 5 min)
- **2-3 changements de pitch** dans la vidéo, pas plus (l'œil mémorise mieux quand un mouvement caméra est "spécial")
- Slow pan continu pendant audio dense = anti-décrochage

### Data-viz
- 1 graphique = 1 idée
- Animation progressive (barres une par une, courbe qui se trace) — jamais tout d'un coup
- Lisible en moins d'1s sur mobile (axe gros, contraste fort)

### Transitions entre actes
Chaque transition acte→acte = un **moment visuel signature** :
- Plein écran chiffre Cinzel gold
- Texture paper kraft + 1 mot
- Carte qui dezoome jusqu'au globe
- Cut sec sur fond noir + nouveau titre acte

## Test des 3 filtres (charte) — appliqués au Mid-form

Sur un Mid-form, les 3 filtres de la charte deviennent **plus difficiles** à tenir (plus de surface, plus d'occasions de glisser) :

1. **Pas de méchant désigné** : sur 700 mots, tentation de personnaliser un acteur en antagoniste. Audit ligne par ligne.
2. **Chaque chiffre = source vérifiée** : Perplexity sonar-pro après script lock, comme pour les Shorts.
3. **Test couper l'audio** : sur 5 min, les couleurs/désaturation ont plus de temps pour coder un jugement moral. Appliquer le test à 3 moments distincts (Acte 1, Acte 2, Acte 4).

## Workflow production Mid-form (proposition)

1. **Pré-production** : script lock + Perplexity fact-check + manifest Mid-form (4 actes timestampés) AVANT tout code
2. **Audio first** : ElevenLabs GéoAfrique V2 OU test Minimax (voir `memory/tools/minimax.md`) → mesure ffprobe → AUDIO_SEGMENTS
3. **Storyboard Gemini 3.1-pro vision** par acte (4 storyboards JSON, pas 1 monolithique)
4. **Code Remotion** acte par acte avec render WIP entre chaque
5. **Self-review** : extraire 8-10 frames (2 par acte), vérifier remplissage + alignement + respirations
6. **Review Gemini** ou Kimi sur MP4 complet
7. **Test rétention manuel** : Aziz regarde sans pause, dit où il a décroché
