## ANALYSE DE L'INSERT "1 500 PERSONNES"

---

### 1. CE QUI MARCHE

| Élément | Pourquoi ça fonctionne |
|---------|------------------------|
| **Le compteur dynamique** | L'accélération de 200→400→950→1350→1500 crée une attente narrative. Le rythme est bien calé sur la voix-off. |
| **La typographie chiffrée** | Graisse épaisse, ombre portée douce → lisibilité maximale sur mobile vertical. L'or mat (#C8A84B) évite le clinquant cheap. |
| **Le cartouche bas** | Positionnement typique des atlas historiques. La bordure fine et le fond parchemin crédibilisent la source. |

---

### 2. AMÉLIORATIONS FAISABLES (Remotion + SVG)

| # | Idée | Technique précise | Impact narratif |
|---|------|-------------------|-----------------|
| **A** | **Pulse de "naissance"** sur le 1500 final | `spring({frame, fps, config: {damping: 14, stiffness: 120, mass: 0.8}})` sur `scale` du `<text>`. Déclenché au frame où "1500" se fige. + `filter: url(#glow-gold)` SVG avec `feGaussianBlur` animé en opacité 0→0.6→0.3 | Souligne que ce nombre est le point de départ fondateur, pas une statistique morte |
| **B** | **Souligné "PERSONNES" qui se dessine** | `<path>` SVG avec `stroke-dasharray` = `pathLength`, `stroke-dashoffset` interpolé de `pathLength` à 0 sur 12 frames via `interpolate(frame, [start, start+12], [pathLength, 0])` | Renforce l'ancrage sémantique, évite l'apparation brutale |
| **C** | **Halo radial diffus** derrière le chiffre | `<circle>` SVG avec `fill="url(#radial-gold)"`, `opacity` animé 0→0.15 sur 20 frames, `scale` 0.8→1.2. Blend mode `screen` via `feBlend` | Crée une "aura" de dignité autour du nombre, différencie bien de l'insert "4000" (trajique) qui aura un halo rouge/orange |
| **D** | **Micro-parallaxe sur le cartouche** | `translateY` du groupe SVG du cartouche : `interpolate(frame, [80, 100], [20, 0], {easing: Easing.outCubic})` + `opacity` 0→1 | Donne de la profondeur, sépare bien les plans d'information |
| **E** | **Grain de parchemin** subtil | `<filter>` SVG avec `feTurbulence` (type="fractalNoise", baseFrequency="0.8", numOctaves="3") en overlay à 3% d'opacité sur le fond noir | Texture atlas historique, cohérence avec Mansa Moussa V2 |

### 3. CE QUI MANQUE (idées nouvelles)

| # | Élément | Réalisation Remotion | Pourquoi essentiel |
|---|---------|----------------------|--------------------|
| **F** | **Silhouettes humaines minimalistes** qui matérialisent l'échelle | 3 rangées de 5 silhouettes SVG (path simple) qui apparaissent séquentiellement (stagger 2 frames) en bas de l'écran, sous le cartouche, en or très transparent (opacity 0.08). Puis fade out quand le cartouche arrive. | Le spectateur ne *ressent* pas "1500". 15 silhouettes = amorçage visuel de la masse, ancrage émotionnel de "petit groupe" vs "empire" |
| **G** | **Compteur qui "respire"** légèrement en loop | `useCurrentFrame()` + `Math.sin(frame * 0.1) * 0.005` sur `scale` du 1500, actif pendant toute la durée du hold. + `brightness` filter variant de 100% à 105% | Évite la rigidité du hold statique, suggère la vie/potentialité contenus dans ce "1500" |

### GARDER / JETER

| | Élément |
|--|---------|
| **GARDER** | Le **rythme du compteur** (200→400→950→1350→1500). C'est la bonne dramaturgie pour un début d'épisode. |
| **JETER** | Le **hold statique** du 1500. Remplacer par le pulse de naissance + respiration + silhouettes pour transformer une information en émotion. |

// Pulse de naissance sur le 1500 final
const finalFrame = 30; // quand le compteur s'arrête
const pulse = spring({
  frame: frame - finalFrame,
  fps,
  config: { damping: 14, stiffness: 120, mass: 0.8 }
});

const scale = 1 + pulse * 0.08; // 8% d'amplification
const glowOpacity = interpolate(pulse, [0, 0.5, 1], [0, 0.6, 0.3]);
