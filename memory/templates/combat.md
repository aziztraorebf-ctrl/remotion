# Template — Scene de Combat (Format 8)
> LIRE EN ENTIER avant d'ecrire le prompt. Ne PAS presenter sans avoir coche la checklist en bas.

---

## Structure du prompt

```
@Image1 is [personnage principal — decrire vetements, armes, traits distinctifs].
@Image2 is [lieu — decrire le terrain, decor, atmosphere].
@Image3 is [ennemis — decrire uniformes, armes, peau/ethnicity EXPLICITEMENT].
@Image4 is [armee alliee — decrire avec diversite visages].
@Image5 is [armes — details close-up].
@Image6 is [atmosphere — fumee, ciel, debris].

[Style]. No text, no banners, no signs, no writing visible anywhere.
No unnecessary 360-degree turns. Without motion distortion.
The human body structure is normal.

0-Xs (Shot 1): [TYPE CAMERA] / [ACTION avec VERBES EXPLOSIFS].
VFX: [effets visuels]
SFX: [sons]

[Repeter — 1.5-2.5s par shot pour combat]

COLOR GRADE: [palette complete].
No words, no music.
```

## Angles camera a varier (NE PAS repeter le meme)

- Low-angle wide shot (ouverture, puissance)
- Side tracking shot (mouvement, vitesse)
- Pull-back widening (reveler le chaos)
- Bird-eye aerial looking DOWN (vue d'ensemble — leader EN TETE du V)
- Push-in medium shot (emotion, blessure)
- Snap zoom close-up (detail, sueur, rage)
- Wide shot steady (finale, silence apres le chaos)

## Verbes a utiliser (JAMAIS "slowly", "gently", "subtle")

SURGES, SLAMS, CRASHES, TEARS, ERUPTS, STRIKES, SWEEPS, CHARGES, BURSTS, THRUSTS, YANKS, CLENCHES, STAGGERS, COLLAPSES

## Techniques DA a considerer

- [ ] Contraste chromatique : heros en couleur vs ennemis desatures ?
- [ ] Blessure progressive : intact -> graze -> sang visible -> cape dechiree -> chute ?
- [ ] Frame chaining : derniere frame du clip precedent comme ref ?
- [ ] Vue aerienne concentrique : heros au centre, cercles de poussiere (signature batailles) ?
- [ ] Desaturation finale : couleur qui drain vers gris en fin de scene ?

## CHECKLIST OBLIGATOIRE — scanner AVANT de presenter

### Images / Refs
- [ ] Diversite visages : CHAQUE individu decrit separement (age, barbe, morphologie, taille) — JAMAIS "5 soldats" sans description individuelle
- [ ] Pas de silhouettes noires pures pour personnages africains — peau brun fonce avec traits VISIBLES
- [ ] Pas d'enfants dans les scenes militaires — TOUS adultes 25-55 ans
- [ ] Ethnicity/peau specifiee explicitement — "pale-skinned European" ou "dark brown-skinned" (R42)
- [ ] "No text, no writing" dans CHAQUE prompt image

### Prompt Seedance
- [ ] Ref image = position de DEPART du personnage (R39)
- [ ] Ref couleurs > prompt couleurs — si ref grise = video grise (R40)
- [ ] Ethnicity/peau dans le prompt Seedance aussi (R42)
- [ ] Blessures progressent entre les shots OU pas de blessure du tout (R43)
- [ ] Leader EN TETE dans les vues aeriennes — "LEADING at FRONT TIP of V-formation" (R51)
- [ ] "no words, no music" a la fin (R54)
- [ ] Compter les caracteres — si >1500 chars, verifier que les derniers shots ne sont pas surcharges (R55)
- [ ] Duree = besoin de la scene, pas 15s par defaut (R56)
- [ ] Pas de "FALLS forward" + slow-mo — decrire la chute en 2 etapes physiques (R48)
- [ ] Canons/objets lourds = arriere-plan, pas premier plan (R49)
- [ ] Apres blessure mortelle = personnage SEUL, pas d'allies inactifs (R50)
