# Template — Scene Narrative (Format 3 SECONDS)
> LIRE EN ENTIER avant d'ecrire le prompt. Ne PAS presenter sans avoir coche la checklist en bas.

---

## Structure du prompt

```
@Image1 is [personnage principal — character sheet 4 vues si possible].
@Image2 is [lieu — decor vide, sans personnages].
@Image3 is [personnages secondaires — avec diversite visages].
[Refs supplementaires si disponibles : armes, objets, mood]

[Style]. No text, no banners, no signs, no writing visible anywhere.
No unnecessary 360-degree turns. Without motion distortion.

SECONDS 0 TO X: [description action + camera + details].
SECONDS X TO Y: [description action + camera + details].
SECONDS Y TO Z: [description action + camera + details].

COLOR GRADE: [palette complete].
No words, no music.
```

## Duree segments

- 3-4s par segment pour 15s (4-5 segments)
- 2-3s par segment pour 10s (4 segments)
- Ne PAS surcharger — 1 action principale par segment

## Angles camera pour scenes narratives

- Wide establishing shot (ouverture, situer le lieu)
- Medium shot steady (dialogue, decision — camera STABLE)
- Push-in lent (tension, revelation — PAS "slight push in" qui avorte)
- Pull-back reveal (montrer le contexte progressivement)
- Over-the-shoulder (negociation, confrontation 2 personnages)
- Close-up visage (emotion cle — "gradually" pour transition douce)

## Mots-cles narratifs

- "gradually" : pour toute revelation progressive (armee, flotte, decor)
- "wind PICKS UP" : pour animer capes, vetements, cheveux
- Micro-expressions : "jaw CLENCHES", "eyes NARROW", "brow FURROWS"
- Personnages secondaires : 1 verbe d'action PROPRE par personnage (R35)

## CHECKLIST OBLIGATOIRE — scanner AVANT de presenter

### Images / Refs
- [ ] Diversite visages : CHAQUE individu decrit separement (age, barbe, morphologie, taille)
- [ ] Pas de silhouettes noires pures pour personnages africains
- [ ] Pas d'enfants sauf si le script le demande explicitement
- [ ] "No text, no writing" dans CHAQUE prompt image

### Prompt Seedance
- [ ] Ref image = position de DEPART du personnage (R39)
- [ ] Ref couleurs > prompt couleurs (R40)
- [ ] Format camera adapte au TYPE de scene — discours = stable, PAS plan-sequence (R41)
- [ ] Pas de "slight push in" — soit STEADY soit ENGAGE (R36)
- [ ] Pas de "color bleeds outward" — changer de plan pour la couleur (R34)
- [ ] Pas de motifs muraux proches des personnages — risque tattoos parasites (R38)
- [ ] "POINTS at" = specifier direction physique, pas le nom du personnage (R33)
- [ ] Personnages secondaires = micro-actions individuelles, pas immobiles (R35)
- [ ] "no words, no music" a la fin (R54)
- [ ] Pas de metaphore lumineuse en 2D flat — "beacon/glow/catches light" = halo magique (R2b)
- [ ] Compter les caracteres — objectif <1500 (R55)
- [ ] Duree = besoin de la scene (R56)
