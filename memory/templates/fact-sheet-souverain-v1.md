**Usage** : à remplir AVANT écriture du script, après recherche (Perplexity Sonar Pro / WebSearch / last30days / sources panafricaines / OSINT). Document interne, jamais diffusé.

## 1bis. Tests Atlas-natif et Récidive vs Événement

**Test Atlas-natif (1-5)** :
- Territoire fixe et cartographiable ? (1 pt)
- Mouvement / déplacement / front mobile ? (1 pt)
- Données chiffrées géolocalisables ? (1 pt)
- Plusieurs pays / échelle continentale ? (1 pt)
- Cartographie ajoute du sens narratif (pas juste illustratif) ? (1 pt)

Score : __ / 5

**Test Récidive vs Événement** :
- [ ] Événement ponctuel daté (ex: attentat, élection, accord) → format **news-driven**, fenêtre de pertinence courte
- [ ] Récidive structurelle (ex: xénophobie SA depuis 30 ans, blocus carburant Mali récurrent) → format **pilier**, sujet stable dans le temps

**Implication format** :
- Atlas-natif 5/5 + Récidive → Long pilier + Short
- Atlas-natif 4-5/5 + Événement → Short uniquement (news)
- Atlas-natif 3/5 + Récidive → Long uniquement (sujet trop social pour Short)
- Atlas-natif <3/5 → reconsidérer pertinence pour Souverain
