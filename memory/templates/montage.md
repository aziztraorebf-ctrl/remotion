# Template — Montage Rapide (Format 7 Beat Sync)
> LIRE EN ENTIER avant d'ecrire le prompt. Ne PAS presenter sans avoir coche la checklist en bas.

---

## Structure du prompt

```
@Image1 is [personnage principal].
@Image2 is [lieu/lieux traverses].
[Refs supplementaires si disponibles]

FORMAT: [duree]s / [N] SHOTS
SUBJECT: [description personnage]
ENVIRONMENT: [lieux]
MOOD: [arc emotionnel]

SHOT 1: [type plan] / [description action] / SFX: [sons].
SHOT 2: [type plan] / [description action] / SFX: [sons].
...
SHOT N: [type plan] / [description action] / SFX: [sons].

COLOR GRADE: [palette complete].
No words, no music.
```

## Rythme

- 10 shots en 15s = ~1.5s par shot (teste et valide 9.5/10)
- 7 shots en 10s = ~1.4s par shot
- Coupes nettes entre chaque SHOT
- SFX par shot = guide le rythme meme si audio est remplace

## Types de plans a varier

ECU (extreme close-up), WS (wide shot), MCU (medium close-up), MS (medium shot), CU (close-up), Insert, Aerial, OTS (over-the-shoulder), Bird's-eye

## ATTENTION

- PAS de ref image gros plan visage = filtre deepfake (R31)
- "@Image1 is the primary character identity" + visage = bloque
