## L'HYPOTHÈSE À EXPLORER (Aziz, prouvée à moitié, à pousser)
**Ce n'est pas le sujet « en général » qui fait vivre ou mourir le style encre — c'est une PROPRIÉTÉ PRÉCISE
du sujet : sa capacité à produire des SCÈNES VIVANTES INCARNÉES plutôt que des CONCEPTS ABSTRAITS.**

Preuve déjà acquise cette session :
- GGW (Grande Muraille Verte) MARCHE : arbres qu'on plante, qui poussent, meurent, reverdissent = des GESTES
  naturels. Le style encre est un style de TRANSFORMATION DU VIVANT.
- Le CFA PEINE (jury 3 modèles = "PowerPoint") : parité/garantie/réserves = mécanismes INVISIBLES → il faut
  INVENTER une métaphore (balance, décret), toujours plus froide que la chose réelle.
- En carte blanche TOTALE, GPT-5.5 ET Gemini ont spontanément fui l'abstrait → choisi le COBALT (ressource
  physique qui VOYAGE : mine→port→finance), pleins de gestes. Les modèles ont instinctivement choisi du PHYSIQUE.

## LE TABLEAU DE TRAVAIL (à valider/affiner en session)
| Le sujet VIT dans ce style (✅) | Le sujet PEINE (⚠️) |
|---|---|
| Une RÉALISATION PHYSIQUE qui se construit/transforme (barrage, muraille verte, mégaprojet, reforestation) | Un MÉCANISME ABSTRAIT (politique monétaire, dette, juridique) |
| Un PROCESSUS NATUREL avec gestes (eau, croissance, migration, érosion) | Un SYSTÈME D'ACTEURS sans corps (institutions, accords) |
| Une TRAJECTOIRE SPATIALE (ressource qui voyage, route, flux) | Une COMPARAISON STATISTIQUE (PIB, taux, ratios) |
| Une TRANSFORMATION D'UN LIEU dans le temps (avant/après, désert→forêt) | Une IDÉE CONCEPTUELLE pure (souveraineté, influence) |

## RAPPELS DE CE QU'ON SAIT DÉJÀ (ne pas re-prouver)
- Style encre = 1 registre, fond+accent selon le ton (PAS un nouveau registre par couleur).
- Mise en scène SVG = révélation/spotlight/transition-encre/échelle/morphing/fil conducteur. ⛔ JAMAIS caméra/viewBox mobile.
- Colorisation = 3 mécanismes (entre-coloré / se-colorise / dé-colorise), fond jamais colorisé globalement.
- Vie continue par-dessus (sin/modulo, sans glissement d'objet inerte).
- Édition SVG directe = transformation 0-API. Gemini compose mieux la mise en scène spatiale ; GLM bon sur objets/schémas.
