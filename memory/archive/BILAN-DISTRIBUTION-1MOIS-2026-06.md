## Décision de priorisation (Aziz 2026-06-28)

1. **YouTube LONG** = priorité n°1. C'est là que se construisent watch time, monétisation, crédibilité, archives.
   Le succès des shorts (~11 abos/vid) justifie de tenter le format long 8-10 min. (Cacao→chocolat short = teaser
   vers ce premier long.)
2. **Facebook** = canal de diffusion à SOIGNER (la diaspora francophone y partage activement — 1100 followers le prouve).
3. **Instagram** = déprioriser (lent, saturé pour l'éducatif sérieux). Maintenir sans y mettre l'énergie prioritaire.
4. **TikTok** = quarantaine. NE PLUS supprimer en masse (cause du shadowban). Soit recréer compte propre plus tard,
   soit ignorer pour l'instant. L'API n'est PAS le problème (sinon bloqué partout).

## Signal décisif

Le plus révélateur n'est pas les abonnés mais les **15 shares + 7 commentaires positifs** sur Sunjata (Facebook) :
un share = décision active de diffusion = le signal le plus honnête sur la valeur perçue. La niche a une audience
RÉELLE qui partage volontairement, sans budget marketing. → la niche est VIABLE ; mois 2 = test de scalabilité.

## Conséquence opérationnelle

Conforte le Hub & Spoke : longs YouTube analytiques = autorité (le hub) ; shorts SVG = entretien + teasers
cross-plateforme (les spokes). Le pari du cacao→chocolat (short qui pointe vers un format long) est aligné avec
cette stratégie.
