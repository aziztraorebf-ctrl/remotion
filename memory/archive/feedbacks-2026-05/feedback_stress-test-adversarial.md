# Stress-test adversarial — règle pipeline

Ajouté en étape 0ter (Souverain) et 6.5 (Héros Oubliés) après analyse de la chaîne James Atlas / @bannedsisyphus.

**Pourquoi :** le jury LLM valide la qualité narrative. Il ne valide pas la solidité face à un adversaire rigoureux. Les deux questions sont différentes.

**Protocole :**
1. Identifier les 3 attaques les plus solides (pas les plus faciles)
2. Chaque attaque a-t-elle une réponse défendable dans le script ?
3. Si oui → OK. Si non → correction 1 phrase max. Si >1 phrase → remonter à Aziz.

**Persona Souverain :** commentateur qui accepte les faits mais conteste le cadrage (romantisation souveraineté, contexte économique investissement, régimes autoritaires présentés positivement).

**Persona Héros Oubliés :** historien sceptique sur la romantisation (anachronisme, omission violences internes, simplification figure historique).

**Why:** Or Africain avait "sans que personne n'en parle" (invérifiable) + présentation des juntes comme mouvement unifié. Niger uranium a tenu le test grâce à la symétrie "Niamey affirme / Orano conteste" systématique.
