# Pourquoi le code bat le storyboard

Validé Niger Uranium Beat 3 v4, 2026-05-10. Aziz a constaté que le rendu code dépassait visuellement le storyboard Gemini.

## 5 facteurs

**1. Vectoriel > raster**
SVG/CSS restent nets à toute résolution. Le PNG storyboard est aplati une fois, ses bords lissés sont définitifs. Les flèches mathématiques sont toujours plus précises que les flèches diffusées.

**2. Storyboard = compromis "tout sur une frame"**
Le storyboard doit montrer toutes les idées en même temps sur une image figée. Il accumule labels écrits, annotations, redondances. L'animation permet de répartir dans le temps (la voix-off remplace les labels écrits).

**3. Gemini 3.1-pro fait un second pass critique sur son propre travail**
En demandant le breakdown technique, on déclenche une rationalisation : il identifie redondances, donne hex codes précis (qu'il n'avait pas spécifiés à la génération), regroupe en timeline cohérente. C'est un second draft involontaire.

**4. Permanent motion ajoute de la vie organique**
Grain qui shift, cercles qui pulsent, marching ants. Le storyboard est figé. Le cerveau humain perçoit le mouvement subtil comme professionnel.

**5. Contraintes techniques imposent rigueur**
Code force à spécifier position exacte, taille exacte, hex exact. Cette contrainte produit naturellement plus crisp que le flou artistique du storyboard.

**Why:** Aziz a posé la question "comment se fait-il qu'on a un résultat peut-être encore mieux que le storyboard lui-même ?" en voyant Beat 3 v4. Comprendre les facteurs structurels permet de reproduire cet effet sur futurs projets.

**How to apply:** Quand un client/Aziz dit "ressemble au storyboard mais en mieux", c'est NORMAL avec ce pipeline, pas un coup de chance. Le storyboard est une cible pas un plafond.
