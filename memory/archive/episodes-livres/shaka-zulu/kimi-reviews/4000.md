## ANALYSE DE L'INSERT "4 000 ZULUS PÉRIRENT"

---

### 1. CE QUI MARCHE

| Élément | Pourquoi ça fonctionne |
|---------|------------------------|
| **Le compteur mécanique** | L'incrémentation rapide (533 → 1466 → 2000 → 3666 → 4000) crée une tension visuelle avant le choc du chiffre final. Ça mime le "décompte macabre" des archives militaires. |
| **Le halo rouge diffus** | Le glow autour du "4000" évoque du sang qui s'étend dans l'eau ou une brûlure — parfaitement adapté au thème de la violence politique. |
| **La typographie contrastée** | Gros chiffre sans-serif épais + sous-titre serif crée une hiérarchie immédiate : le chiffre parle avant le texte. |

### CODE CLÉ POUR REMOTION (snippet)

```tsx
// Spring "lourd" pour le 4000
const impact = spring({
  frame,
  fps,
  config: {
    mass: 3,
    damping: 15,
    stiffness: 80,
  },
  from: 0,
  to: 1,
  delay: 30, // attend que le compteur arrive à 4000
});

// Tremblement post-impact
const shake = frame > 60 && frame < 72 
  ? Math.sin(frame * 0.8) * 2 * (1 - (frame-60)/12)
  : 0;

const scale = interpolate(impact, [0, 1], [0.8, 1], {extrapolate: 'clamp'});

// SVG text
<text 
  x="540" 
  y="600" 
  transform={`translate(0, ${shake}) scale(${scale})`}
  style={{ transformOrigin: 'center' }}
>
  4000
</text>
```
