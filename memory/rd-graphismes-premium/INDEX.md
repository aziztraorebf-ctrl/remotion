## SYNTHÈSE RAPIDE — Les 3 recherches réunies

### Ce que nos concurrents font (la chaîne complète)
1. Template Envato de base → customiser couleurs/typo
2. GEOlayers 3 pour les cartes animées (notre Mapbox fait mieux)
3. Artgrid/Pexels pour le B-roll terrain (notre seul gap)
4. Artlist/Epidemic Sound pour la musique
5. Fiverr pour les parties complexes ($10-15/short)

### Notre avantage technologique (confirmé 3 recherches)
| Ce que nos concurrents font | Notre stack | Verdict |
|------------------------------|-------------|---------|
| GEOlayers + AE | Mapbox + Remotion | **Nous > eux** |
| Templates Envato customisés | Code 100% custom | **Nous > eux** |
| Chartist data viz | CountUp / SankeyBlocs | **Équivalent** |
| Particules AE | SVGGrain léger | **Nous > eux** |
| B-roll terrain stock | Seedance/Kling i2v | **Gap — à combler** |
| @rileybrown (1 926 likes) documente Remotion + GPT 5.5 comme la nouvelle référence | Notre stack exact | **On est en avance** |

### Les 5 règles de production à appliquer immédiatement

| # | Règle | Source | Application |
|---|-------|--------|-------------|
| R1 | **Changement visuel toutes les 3-5s** (pas 5-7s) | AIR Media-Tech, R1+R3 | Glow/float ne comptent pas |
| R2 | **B-roll émotionnel 20-30% du temps écran** | insidetheedit.com, R3 | Kling i2v depuis image Gemini |
| R3 | **Cut speed = miroir du registre script** | @tryahdd, R3 | Factuel → damping 80+ / Révélation → stiffness 200+ |
| R4 | **Stat à l'écran = simultané avec la voix-off** | AIR Media-Tech, R3 | Vérifier timing.ts frame par frame |
| R5 | **Pattern interrupt toutes les 60-90s** | Video Editors Anonymous, R3 | Obligatoire pour beats > 90s |

### Le fond texturé + typo bold = premium (Recherche 1, confirmé R2)
- Fond texturé cohérent → SVGGrain ✅ déjà dans notre stack
- Typographie bold → Tailwind text-gold, Bebas Neue ✅ déjà dans notre stack
- Le problème n'est pas l'outil — c'est l'exécution beat par beat

### Notre seul vrai manque
**B-roll terrain** — 20-30% du temps écran dans les vidéos haute rétention.
Solution recommandée : Envato Elements stock video géopolitique (déjà abonnés ?) ou Kling i2v depuis image Gemini contextuelle.
