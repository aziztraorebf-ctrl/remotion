- Fond carte : navy quasi-noir `#0A1628` à `#0F1F38` (océans), masse continentale `#3A4A6E` (bleu ardoise un peu désaturé)
- Pays highlighted (DRC) : beige clair `#E8DDC4` (sablé, contraste fort sur navy)
- Banner inférieur : noir profond `#0B0B0E` + texte blanc `#FFFFFF`, sous-bandeau jaune-or `#E8B33A` (logo Africa Amplified)
- Cadre titre : trait jaune-or `#E8B33A` sur card noir
- Studio (anchor) : bleu cyan vif `#1F8FC9` (veste anchor) sur arrière-plan tour Johannesburg pastel
- Footage live : palettes terreuses (ocre `#B07A3A`, jaune Volvo/CAT `#F2C72D`, terre brune)
- Ratios approx (frame map) : 70% navy, 18% beige (DRC), 8% bandeau or, 4% texte blanc

## Mood
- Newsroom premium + map graphic codifié. Le bandeau or n'est PAS narratif (c'est le branding de l'émission), mais contraste très "Or Africain V5".
- Très dépendant du footage live : ~70% du Short = b-roll, ~15% map, ~15% talking head.

## Assets
- Carte monde équirectangulaire avec frontières fines blanches `#FFFFFF`@30% — projection plate (PAS Mercator centré-Afrique, c'est une carte monde recadrée).
- Cartouche label "DEMOCRATIC REPUBLIC OF THE CONGO" : rectangle noir 80% opacité + bordure jaune-or 1px + texte blanc sans-serif (look Helvetica/Neue Haas).
- Pin / hotspot : petit cercle blanc + ombre noire sur le pays highlighted.
- Tier inférieur : 2 layers — bandeau show (or) + bandeau headline (noir/texte blanc).
- Lower-third Ramaphosa : card blanc + nom noir + titre gris, plus barre date "Nov. 3, 2023" en haut gauche.
- Logos drapeaux (US/AU) en arrière-plan d'interview.
- Source watermark texte simple "SOURCE: GLENCORE" coin haut-gauche, blanc 60%.

## Mouvements caméra
- Footage live : drone aerial slow push-in sur dump truck, slow pan latéral sur ouvriers en passerelle.
- Map graphic : fade-in + très léger zoom in (peut-être 1.0 → 1.04 sur 2-3s). Pas de drift, pas d'orbit. Statique-quasi.
- Cuts rapides : ~2-3s par plan, montage Bloomberg classique broadcast.
- Pas de transition fancy — straight cuts + dissolve occasionnel.

## Reproductible Mapbox/Remotion ?
- ✅ Le map graphic est 100% reproductible : style sombre + un pays mis en valeur (lighten layer fill DRC), label cartouche + pin = pattern Or Africain Beat 3 déjà validé.
- ❌ Tout le b-roll mining = pas reproductible sans stock footage payant (Glencore source).
- 🟡 Le bandeau "show branding + headline" est imitable mais c'est un signal broadcast TV qui peut alourdir un Short YouTube vertical.

## Verdict
- Palette : 🟡 quasi-identique à Or Africain V5 (navy + or + beige). Risque de doublon visuel.
- Assets : 🟢 le pattern map+cartouche+pin est solide, déjà dans notre toolkit.
- Caméra : 🔴 trop statique pour Short vertical (Bloomberg ne porte pas le mouvement).
