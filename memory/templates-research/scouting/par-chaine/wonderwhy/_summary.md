## Signature visuelle (cross-vidéos)
Pédagogie cartographique chaude : satellite imagery comme base permanente, polygones territoriaux remplis de couleur plate (alpha ~0.6-0.7) qui mute dans le temps pour transmettre les changements de souverain. Fonds texturés contextuels (kraft, sable, parchemin) pour les "fiches d'étude" entre plans cartographiques. Drapeaux SVG plats omniprésents comme avatars d'États, parfois avec bulles dialogue.

## Différenciation vs Or Africain V5
Or Africain = noir + or + ledger (luxe financier, sobriété).
WonderWhy = beige/sable + satellite + drapeaux saturés (manuel scolaire chaleureux).
Différencié ☑ fortement / ⬜ moyennement / ⬜ faiblement
→ Aucun risque de confusion. WonderWhy peut servir de **pôle complémentaire** dans une rotation de templates Souverain : ledger pour épisodes "argent/contrats", WW-style pour épisodes "frontières/géopolitique territoriale".

## Synthèse 3 axes

### Axe 1 — Palette
- Verdict consolidé : 🟡 — palettes chaudes lisibles mais incompatibles avec signature ledger Or Africain. À ne pas copier ; à étudier comme contre-modèle.
- Top idée backlog : **fond texture contextuelle par épisode** (lingot d'or pour or, schiste pour pétrole, papier officiel pour traités) au lieu d'un noir uniforme.

### Axe 2 — Assets / figures
- Verdict consolidé : 🟢 — patterns reproductibles immédiatement, économiques.
- Top idée backlog : **drapeau + bulle dialogue** pour faire "parler" un État dans un débat géopol (ex: France vs Niger sur uranium, BHP vs Mali). Évite les portraits humains, évite la moralisation, garde la lisibilité.

### Axe 3 — Mouvements caméra
- Verdict consolidé : 🟢 — pattern "carte fixe, le temps passe par la couleur" est exactement l'outil narratif manquant pour Souverain (avant/après nationalisations, concessions minières).
- Top idée backlog : **morph chromatique chronologique** sur polygone fixe — un même territoire passe de couleur "colonie" → "indépendance" → "nationalisation" → "concession étrangère" sans que la caméra bouge. Lerp `fill-color` Mapbox via Remotion `interpolateColors`.

## Recommandation
Pour la dissection (Jour 2) : ☑ retenir / ⬜ retenir partiellement / ⬜ écarter
