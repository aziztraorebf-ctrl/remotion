## Axe 1 — PALETTE 🟡

- Carte fond : papier blanc quadrillé `#F4F5F8` + grille fine `#D8DDEA`
- Pays "actifs" (anti-français) : aplat bleu `#4A8AC8` saturé
- Pays "neutres" : blanc `#FFFFFF` avec relief topographique léger
- Drapeau France : tricolore natif `#0055A4` `#FFFFFF` `#EF4135`
- Yeux mascotte : blanc + iris noir `#000000`
- BIG WORD overlay : violet/bleu `#6877C9` (même que vidéo SA)
- Verdict 🟡 : palette CARTE TLDR = bleu pastel + papier quadrillé = très cartoon-éditorial. Pas alignée Souverain dark, mais le pattern "pays actif aplat saturé / pays passif blanc neutre" est UNIVERSAL.

## Axe 2 — ASSETS 🟢🟢 (pépite)

- **MASCOTTE PAYS** : silhouette France découpée + drapeau intérieur + 2 yeux gros écarquillés (style cartoon Editorial). PÉPITE wildcard ABSOLUE.

- Bordure pays = trait noir fin `#000000` 1.5px
- Drapeau pastille (ronde, drapeau dans cercle) — même pattern que vidéo 1
- Articles screenshots France24 incrustés (cadre blanc + ombre légère portée) à côté du host

- Verdict 🟢🟢 : la MASCOTTE PAYS (silhouette + drapeau + yeux) = signature TLDR identifiable instantanément. Pour Souverain ce serait off-brand mais c'est un OUTIL de personnification d'un pays sans devoir mettre un dirigeant. À garder en backlog "wildcard humour" si jamais Souverain veut un beat allégé.

- Verdict 🟡 : zoom carte simple + entrée d'asset latérale = pattern CLASSIQUE cartographique. Souverain fait déjà mieux (zoom Mapbox 3D Atlas). Pattern split-screen host+articles utile pour Souverain "exposé sources".
