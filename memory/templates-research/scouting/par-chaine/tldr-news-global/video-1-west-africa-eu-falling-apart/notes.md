## Axe 1 — PALETTE 🟡

- Fond motion : noir profond `#000000` (pas pur, légère texture grain)
- Vert primaire formes : `#1FB855` saturé
- Magenta/rose : `#E91E8B` → `#D81B60` (gradient diamant)
- Jaune saturé : `#FCD90A`
- Bleu logo TLDR : `#3B5FE3` (sur écran fin)
- Drapeaux pays = couleurs natives (rouge `#C8102E`, jaune Guinée, vert)
- Texte : blanc pur `#FFFFFF` sur formes
- Verdict 🟡 : palette VIVE pure (vert/magenta/jaune satures sur noir) à l'opposé de Souverain dark premium. NON-utilisable directement, mais leçon : sur fond noir, 3 couleurs pures saturées suffisent à structurer un point.

## Axe 2 — ASSETS 🟢

- Formes géométriques colorées plein-pop (carré arrondi vert, losange magenta, cercle jaune) — chacune contient un mot-concept
- Photos pays/leaders en POLAROID (cadre blanc + ombre + pseudo-écriture script "Alpha Condé") sur fond carte
- Drapeaux en pastilles rondes avec bordure bonbonée
- Cartes : pays = aplats couleurs vives, fond bleu pastel `#A8C8E8`, frontières blanches fines, hachures diagonales pour pays sortants ECOWAS
- Portraits leaders en CUTOUT inscrits dans la forme géométrique (Burkina dans carré vert, Mali dans losange magenta, Niger dans cercle jaune) — ASSOCIATION CHROMATIQUE INSTANTANÉE
- Screencast Ground.News (article mis en avant + zoom box noire sur "Total News Sources 495") 
- Verdict 🟢 : pattern POLAROID + drapeau-pastille = REPRODUCTIBLE Souverain et premium-compatible si palette adaptée. Pattern "portrait dans forme géométrique colorée" = signature d'identification rapide pays/personne.

## Axe 3 — CAMÉRA 🟡

- Coupe sèche dominante (hors stock footage live)
- Stock footage : zoom doux 5-8% sur 3-5s (pan léger pour donner vie)
- Motion design : entrées des formes échelonnées (scale 0→1 + fade) avec décalage 100-200ms entre éléments
- Screencast : tilt-perspective 3D légère (~5°) + zoom box noire highlight ligne par ligne
- Cartes : pas de zoom Mapbox, statiques avec drapeau-pastille qui pulse
- Verdict 🟡 : pas de virtuosité caméra. Les "mouvements" sont des entrées séquentielles d'éléments (one-by-one beat). Densité = couches qui s'ajoutent, pas trajectoire caméra. Réutilisable comme pattern de pacing.
