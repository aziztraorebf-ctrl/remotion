# TLDR News Global — "How South Africa Became a Failed State"

- URL : https://www.youtube.com/watch?v=ZxKzIdBTmPE
- Durée : 792 s (~13 min)
- Sujet : Afrique du Sud, déclin économique, ANC, infrastructure
- Date scout : 2026-05-08

## Ratio live-action / motion design

- Talking head host (cadre studio, néon TLDR) : ~40%
- Motion design overlay sur talking head : ~35%
- Charts/data viz pleine page : ~15%
- B-roll stock léger : ~10%

>50% live (host + overlay), motion design pur ~25%. LIMITATION SIGNALÉE — vidéo plus "essai studio" que carto rapide. Mais les overlays gardent une signature lisible.

## Axe 1 — PALETTE 🟢

- Fond studio : pastel cyan/menthe `#C5DCE0` (chaleureux, propre)
- Néon TLDR : turquoise `#5EE3D4`
- Overlay box mot-clé : violet/bleu translucide `#5C6FE0` à `#4A5DD8` (alpha ~0.85)
- Texte sur overlay : blanc pur `#FFFFFF`
- Charts : rouge `#E33B3B` (declin) vs vert `#3BB85C` (positif), donut multi-couleurs (orange `#F58220`, violet `#7E5AB5`, bleu pastel `#C9CFE8`)
- Texte titres charts : bleu vif `#4A6BE0`
- Logos partis : couleurs natives mais opacité réduite à 0.4 si désactivé/inactif
- Verdict 🟢 : palette OVERLAY translucide bleu = pattern utilisable pour Souverain (chambre de marchand sombre + overlay fait passer un mot-clé sans coupure visuelle). Le bleu translucide alpha est très "premium éditorial".

## Axe 2 — ASSETS 🟢

- BIG WORD overlay : box pleine couleur (alpha ~0.85) couvrant 80% écran sur talking head, mot-clé en BOLD HUGE (PARTY FACTIONALISM, VANDALISM BURGLARY, LITTLE MONEY UPGRADE GRID)
- Charts : line chart avec dots pleins aux jonctions années + grid clair, donut chart à parts colorées (animation dessin progressif)
- Logos partis politiques : grille 5×2 avec halo blanc circulaire derrière, certains atténués
- Fond papier quadrillé léger `#F4F5F8` avec lignes fines `#E5E7F0`
- Verdict 🟢 : technique BIG WORD overlay translucide = pépite réutilisable Souverain (sur chambre marchand sombre, overlay bleu-foncé translucide avec mot-clé HUGE → garde la chair humaine + insère le concept). Charts = standard mais propres.

## Axe 3 — CAMÉRA 🔴

- Talking head : zéro mouvement caméra (statique fixe)
- Charts : entrée animée (line draws progressivement, donut wedges apparaissent un par un)
- Overlay : fade in/out simple (200ms)
- Pas de zoom carte, pas de pan, pas de tracking
- Verdict 🔴 : caméra TRÈS pauvre. Tout repose sur les entrées d'éléments + les charts. Pas d'inspiration caméra à tirer.

## Densité info / seconde

- Frame 45 : line chart (8 années + 2 séries) + question titre + donut chart cumulés en 1 plan = 17+ unités d'info
- Frame 133 : 10 logos partis (5×2 grid), 4 acronymes textuels = 14 unités d'info en 1 plan
- Pattern : chart animé progressivement étire la lecture sur 4-6s, mais densité finale élevée

## Observations

- TLDR utilise BIG WORD overlay comme PONCTUATION de la voix-off — chaque mot-clé important devient une box pleine écran 0.5-1s puis disparait
- C'est une technique très efficace pour youtube-essay : remplace le b-roll quand on n'en a pas
- Pour Souverain Short 75s, ça pourrait fonctionner sur un beat de "concepts clés" listés rapidement (chaque mot-clé = 0.5s pop)
- ATTENTION : trop d'overlay sur talking head = ressort vidéo "low-budget essay" si fait sans soin. Souverain doit garder du visuel cartographique pour son ADN.
