# The Pudding — The Big Data of Big Hair

- URL : https://www.youtube.com/watch?v=fzwrpAfMdKw
- Durée : ~3:00
- Format : 16:9, motion data-viz (essai web transposé)
- Type : data-journalisme pur, zéro live action

## Palette
- Fond cream/ivoire `#F4EFE6` (~85% du temps écran)
- Texte noir `#111111` serif éditorial (~10%)
- Accent vert sapin `#2E5E3E` (lignes de chart, label "Women")
- Accents rouge `#C8443A` + jaune moutarde `#E2B73D` (pastilles décoratives titre uniquement)
- Photos yearbook noir & blanc grain argentique (~30% mid-video)
- Ratio palette : cream 60% / B&W photo 25% / texte noir 10% / accents 5%
- Verdict : 🟡 — palette éditoriale soignée mais cream très saturé culturellement (US yearbook). Adaptable Souverain seulement avec ré-encodage couleurs (vert→or, cream→sable).

## Assets
- Photos d'archives B&W rectangulaires (signature photo yearbook)
- Tiles grids massifs (~140 portraits en damier comme background de chart)
- Pastilles colorées géométriques décoratives (titre seul)
- Line charts SVG simples 1 série, label inline droite
- Texte serif éditorial type "Tiempos Headline" / "Domaine"
- Ligne pointillée verticale séparation ("Min" / "Women")
- Verdict : 🟢 — pattern "chart sur grille de portraits" hautement réutilisable. Substituer photos par drapeaux/blasons africains = directement Souverain-compatible.

## Caméra
- Quasi statique. Crossfades doux entre cards pleine page texte.
- Animation principale = stroke draw de la courbe ligne par ligne (small multiples staggered).
- Zoom out panoramique sur grille photos (mosaïque qui se construit puis recule pour révéler la chart par-dessus).
- Pas de pan, pas de tilt, pas de parallax.
- Verdict : 🟡 — le zoom out grille→chart est un pattern intéressant pour révélation "voici les N pays, voici leur trajectoire". Le reste = trop static pour un Short vertical.

## Top observations Souverain
1. **Pattern "grille comme background de chart"** : 140 vignettes + courbe par-dessus = densité info sans surcharge. Pour Souverain : 54 drapeaux Afrique en grille + courbe PIB/dette par-dessus.
2. **Small multiples avec portrait label** (frame 003) : 3 lignes empilées, photo+nom à gauche, courbe à droite, annotation inline. Adaptable : 3 pays empilés, drapeau+nom, courbe ressources.
3. **Stroke draw timing** : la courbe se dessine en sync avec le voice-over qui annonce le pic. Très exploitable Souverain.

## À éviter
- Cream si trop chaud → risque collision palette Or Africain locked.
- Photos B&W comme accent : Souverain charte = portraits couleurs ou silhouettes graphiques.
