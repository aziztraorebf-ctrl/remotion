# Kurzgesagt — Is The World Getting More Violent?

ID: reSfF60-2S4 | Sujet : conflits & géopolitique post-1945
Statut anti-modèle : signature visuelle exemplaire, narratif éditorial proche de Souverain (data-driven, voix calme).

## Axe 1 — Palette 🟢
- Background dominant deep purple/indigo `#1F1147` (~`#1A1340`–`#241657`) ≈ 35-45% des frames "data".
- Scènes terrain : palettes contextuelles désaturées (sable `#C9B27A`, vert kaki `#7A8B5A`, bleu poussière `#9DB1C2`).
- Bandeau accent orange-doré `#D88A1E` (titre "Russian Invasion of Ukraine") = signature ribbon.
- Accents narratifs : rouge `#E5413A` (frontière conflit), bleus saturés `#1B6EFF` (data points), violet hub `#5527C6` (numéro 5).
- Ratio dominantes : **purple-bg 45% / contextuel-désaturé 40% / accents pure-saturated 15%**.
- Clé identité : tout fond non-violet est **désaturé** ; toute donnée/highlight est **saturée pure**. Contraste sat = hiérarchie.

## Axe 2 — Assets 🟢
- Personnages "pilule" hyper-stylisés (capsule arrondie avec bandes color-block tête/torse/jambes) — réutilisables à l'infini, ethnies variées en quelques bandes.
- Buildings flat-2D 4-tons (corps, fenêtres répétées, ombre soft, toit accent).
- Typo titre : geometric sans bold blanche `#F1ECDF` sur ribbon orange (Hauora-like).
- Numéro chapitre dans pastille violette `#5527C6` (chiffre blanc) — wayfinding répété.
- Iconographie data : dots colorés (jaune, mint, bleu) = comparaison qualitative sans label = lisible sans lecture.
- Chain/breaking-chain icon = métaphore visuelle récurrente Kurzgesagt.
- Particules grain léger `+noise` sur scènes terrain (texture organique).

## Axe 3 — Caméra 🟡
- 95% **plans fixes**, mouvement vient des assets (push-in subtil, parallax léger nuages).
- Split-screen frame-001 = comparaison binaire (russe gauche / défense droite) — pattern réutilisable.
- Transitions : cuts secs sur beat audio + zoom-out vers carte/data view.
- Aucun whip-pan, aucun mouvement spectaculaire — **autorité = calme**.

## Recette technique (reproductibilité Souverain)
- Reproductible : **palette 3 niveaux (fond signature / contextuel désaturé / accent pure)**, ribbon titre orange, pastille numéro chapitre, dots data sans label.
- NON-reproductible : illustrations vectorielles personnages/buildings (artistes pro, semaines de prod).
- À voler : **discipline de désaturation des scènes contextuelles** + **pure saturation réservée aux données**. C'est le secret de leur cohérence cross-vidéos.
