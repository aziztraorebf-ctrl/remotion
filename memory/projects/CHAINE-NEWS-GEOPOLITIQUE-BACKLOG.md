## Les 3 formats techniques applicables

### Format 1 — "data-viz-driven" (Remotion pur SVG)
- Exemple : "Pourquoi Wadagni est elu a 94% au Benin"
- Composants : narration ElevenLabs + titres animes + frise chronologique + chiffres animes (spring/interpolate)
- Coût : **$0.60-1 par Short** (ElevenLabs + 0-2 images Gemini optionnelles)
- Le plus rapide a produire (~1h)
- Ideal pour : mecanismes institutionnels, donnees economiques, comparaisons chiffrees

### Format 2 — "map-driven" (pipeline Historical Map)
- Exemple : "Pourquoi le Niger a coupe ses liens avec la France"
- Composants : carte d3-geo animee (parchment Gemini + projection) + icones Gemini + narration + musique ambient
- Coût : **$3-5 par Short**
- Pipeline de référence (archivé) : `memory/archive/historical-map-pipeline.md`
- Ideal pour : conflits, alliances geopolitiques, expansions/retraits territoriaux

### Format 3 — "clip-driven narratif" (storyboard-to-video Seedance)
- Exemple : "Ce que les BRICS ont decide cette semaine pour l'Afrique"
- Composants : 1-2 clips Seedance multi-shots + cartes Remotion + data viz + narration
- Coût : **$8-12 par Short**
- Ideal pour : portraits de leaders, narrations dramatiques, evenements visuellement riches

## Avantages structurels vs Heros Oublies (a l'epoque)

| Contrainte | Heros Oublies | News geopolitique |
|------------|---------------|-------------------|
| Identite personnage locked sur toute duree | obligatoire | pas necessaire |
| Coherence historique costumes/decors | recherche longue | imagery contemporaine OK |
| Narration emotionnelle continue | critique | utile mais pas central |
| References visuelles a creer | char sheets + env plates | stock-like (cartes, drapeaux, photos generiques) suffit |

Resultat estime : coût moyen **5-10x inferieur** par Short par rapport a Heros Oublies (~$40/Short).

## Pieges identifies

### Piege 1 — Reactivite editoriale
News datees = perissables. Si on sort un Short Niger 2 semaines apres tout le monde, zero views. Necessite cycle production rapide (< 48h ideal).

### Piege 2 — Sujets sensibles politiquement
Geopolitique africaine = mines politiques (autocrates, dictatures, conflits). Définir une **ligne editoriale claire** avant publication (neutre factuel / critique-militante / pedagogique) — jamais tranché avant l'abandon de facto de l'idée.

### Piege 3 — Volume vs qualite
Tenir 2-3 Shorts/semaine = risque de baisse qualite si formalisation pipeline insuffisante.
