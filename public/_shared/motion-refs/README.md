# Motion Reference Library

Video reference clips for Seedance 2.0 Omni (reference-to-video).
Each clip captures a CAMERA MOVEMENT pattern, not content.
Seedance copies the motion/camera/rhythm, not the visuals.

## Usage

Upload as `@video1` in Seedance Omni + image refs for character identity.
Tag in prompt: `@video1 follow for camera movement and pacing`

## Rules

- Max 15s cumulative video refs per Seedance generation
- Sweet spot: 1 video ref of 4-8s
- These refs are REUSABLE across all projects
- Content doesn't matter — only the camera path does
- Always pair with image refs for character/style identity

## When to use ref video vs text-to-video

| Situation | Use |
|-----------|-----|
| Complex camera movement | REF VIDEO |
| Choreographed action | REF VIDEO (combat clip) |
| Calm/contemplative scene (rule 68) | REF VIDEO (push-in or tracking) |
| Simple static shot | TEXT-TO-VIDEO |
| Multi-cut montage | TEXT-TO-VIDEO (Format SHOT) |
