# _demos/ — ZONE GELÉE (démos shorts de référence livrées)

⛔ **NE PAS coder ici. NE PAS s'en inspirer comme source de vérité.**

8 démos shorts complètes déjà livrées (afrique-numerique, anomalie-montreal, cobalt-rdc, mansa-moussa,
niger-uranium, petrole-patience, sonjata, warmap-sahel). Consultables comme exemples assemblés, mais :

- **Nouveau proto** → `src/projects/_rnd/<sujet>/` (PAS ici).
- **Nouveau livrable** → `src/projects/<pilier>/<episode>/` (PAS ici).
- **Brique réutilisable** → `src/projects/_shared/components/` (les vraies briques vivent là, pas dans ces démos).

⚠️ Piège connu : un sujet peut exister à la fois dans `_demos/` (vieille démo) et être redemandé en livrable.
Ne PAS éditer la démo `_demos/` — créer le nouveau dans la bonne zone. Sinon = 2 versions du même sujet.

Règle complète des zones : `src/projects/_shared/INTENTION-FORME-INDEX.md` (section « OÙ RANGER CE QUE JE CODE »).
